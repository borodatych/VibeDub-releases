# VibeDub

Перевод и озвучка видео на вашем Mac. Скачиваете образ, перетаскиваете приложение в
«Программы» — дальше всё происходит на вашей машине: ни загрузки фильма на чужой сервер,
ни регистрации, ни подписки на сервис.

Этот репозиторий — только для выпусков. Исходный код закрыт; здесь лежат готовые сборки
и описание того, что в них изменилось.

## Скачать

Последняя сборка — на вкладке [Releases](../../releases/latest): файл `VibeDub-<версия>.dmg`.

## Что умеет

- **Перевод и озвучка любого видео** — файл с диска или ссылка. Голос оригинала убирается,
  музыка и звуки сцены остаются; поверх ложится озвучка на нужном языке. 36 языков в обе
  стороны, язык оригинала определяется сам.
- **Голос под говорящего.** Реплики разных людей получают разные голоса, подобранные по полу
  и высоте голоса оригинала, — фильм не читает один диктор.
- **Субтитры на лету.** Включаются прямо во время просмотра: речь распознаётся и переводится
  в реальном времени, ждать целого перевода не нужно.
- **Просмотр по ходу перевода.** Длинное видео можно смотреть с самого начала, пока
  остальное ещё готовится.
- **Поиск источников.** Поиск фильма по нескольким площадкам из самого приложения; ненужные
  выключаются в настройках.
- **Свои субтитры файлом.** Готовый перевод выгружается в `.srt` — можно смотреть в любом
  плеере.
- **Улучшение картинки** — отдельная задача: шумодав, резкость, ровная громкость.
- **Очередь задач.** Несколько файлов за раз, пауза, продолжение с того же места после
  закрытия приложения, остановка с полной уборкой.

## Что нужно

- Mac на Apple Silicon, macOS 13 или новее.
- Около 3 ГБ свободного места: само приложение (~1,4 ГБ) и модели распознавания (~1,6 ГБ),
  которые докачиваются при первой задаче.
- Для перевода — подписка Claude Code (войти в неё) **или** ключ Anthropic API; ключ
  вводится в настройках приложения.

## Первый запуск

1. Откройте `.dmg` и перетащите **VibeDub** в «Программы».
2. **Первый раз открывайте только правым кликом → «Открыть» → «Открыть».** Обычный двойной
   клик macOS отклонит: у приложения нет подписи Apple — платной учётной записи разработчика
   у проекта нет, и система говорит об этом грубее, чем оно есть. Дальше приложение
   открывается как любое другое.
3. При первой задаче скачаются модели распознавания. Прогресс и кнопка «Скачать заранее» —
   в настройках, раздел «Модели».

Приложение работает в фоне: закрыли окно — задачи продолжаются, пока вы явно не остановите
сервер. Ваши переводы лежат в `~/Library/Application Support/VibeDub` и переживают
обновление приложения.

## Если что-то не заработало

Приложение пишет журнал в `~/Library/Logs/VibeDub/server.log`; тот же журнал виден в самом
приложении — кнопка журнала справа в шапке. Последние строки оттуда — это ровно то, по чему
видно, что упало. Заводите [issue](../../issues) с ними.
